Alliance typeface (Degarism Studio) is a licensed font and is not bundled.

To use it:
1. Obtain/purchase the font and convert to .woff2.
2. Place these files in this folder:
   Alliance-Regular.woff2   (weight 400)
   Alliance-Medium.woff2    (weight 500)
   Alliance-Bold.woff2      (weight 700)
3. Nothing else to change; src/index.css already declares them.

If the files are missing, the site automatically falls back to a clean system sans-serif.
